# 📰 Fake News Detection
A Machine Learning model to classify news articles as real or fake using Natural Language Processing (NLP) techniques.

# 📌 Features
✅ Preprocessing of text data (tokenization, stopword removal, vectorization)
✅ Implementation of machine learning algorithms (Logistic Regression, Naive Bayes, etc.)
✅ Model evaluation with accuracy, precision, recall, and F1-score
✅ Dataset handling and visualization

# 🚀 Technologies Used
Python
Scikit-learn
Pandas & NumPy
NLTK
TfidfVectorizer
📂 Dataset
The model is trained on a labeled dataset containing real and fake news articles.
